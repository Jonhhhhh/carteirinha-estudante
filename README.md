# 🪪 Carteirinha Digital de Estudante - Celso Lisboa

Aplicação web interativa, leve e moderna para visualização, edição em tempo real e exportação de carteirinhas digitais de estudante personalizadas para o **Centro Universitário Celso Lisboa**.

---

## ✨ Funcionalidades

- **Edição em Tempo Real:** Edite os dados diretamente clicando no texto da carteirinha ou utilize o painel lateral com sincronização instantânea.
- **Upload de Foto:** Atualize a imagem do estudante diretamente do seu dispositivo com pré-visualização em alta qualidade.
- **QR Code Dinâmico:** Atualização automática do QR Code conforme o conteúdo e parâmetros de validação digitados.
- **Exportação em Alta Resolução:** Baixe a carteirinha pronta em formato PNG de alta qualidade com um clique.
- **Modo de Impressão:** Formatação e layout otimizados para impressão física e geração de PDF.
- **Visualização Limpa:** Modo de pré-visualização sem guias visuais e sem botões de edição para conferência rápida.
- **100% Client-Side:** Não requer backend, banco de dados ou dependências locais complexas; roda diretamente no navegador.

---

## 🚀 Como Executar

### Opção 1: Diretamente no Navegador (Local)
Basta abrir o arquivo [`index.html`](index.html) em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).

### Opção 2: GitHub Pages (Online)
Para publicar e acessar o app pelo celular ou computador através da web:
1. Vá até as **Configurações (Settings)** do repositório no GitHub.
2. No menu lateral, acesse **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/(root)`.
4. Clique em **Save**. Em poucos minutos sua carteirinha estará disponível online em:
   `https://jonhhhhh.github.io/carteirinha-estudante/`
